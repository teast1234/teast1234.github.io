Ren'Py coding assistant

Lets Cursor or Claude work inside a Ren'Py project: list labels, trace references, inject script, run compile/lint, and auto-fix common mistakes. Fewer window switches while writing a visual novel.

MCP · Writing

CSDN-MCP

CSDN drafting assistant

Wraps outline, drafting, SEO checks, login, and publish as MCP tools. Writing stays local; publishing defaults to the draft box so a human can review before anything goes live.

  • CSDN
  • SEO

NewsCrawler MCP

Financial data for agents

Feeds agents Yahoo, CNBC, RSS, and related news sources, plus Yahoo / Investing OHLCV history over stdio. Handy for research chats, ticker lookup, and candle queries.

  • News

Voice

TTS · Windows

GPT-SoVITS For AB

Character voice trainer

A Windows one-click pack on GPT-SoVITS: install, separate vocals, slice, transcribe, train, and infer from a web wizard. The repo ships scripts only, so it stays small and ready for game dubbing or fan TTS.

  • GPT-SoVITS
  • One-click
  • Dubbing
GitHub Gitee

Gojo Satoru RVC

Realtime voice pack

An RVC WebUI pack with a Gojo Satoru model and index built in. Dub offline, or change your voice live from a microphone and route it into chat apps through a virtual cable.

  • Realtime
  • Portable
