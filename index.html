04

开源项目

仓库分开放。国内镜像和一键包主要在 Gitee，GitHub 上是同一套公开身份下的代码。

Gitee

renpy-mcp

15 个工具，让 AI 读 Ren'Py 脚本、改代码、跑编译，并修 return、from 这类常见问题。

 Gitee

CSDN-MCP

把搭骨架、写正文、SEO 自检和存草稿收成一组工具。发布前先留在草稿箱。

 Gitee

NewsCrawler MCP

Yahoo、CNBC、RSS 和行情 K 线，用 stdio 接进 Cursor、Claude 或 Spring AI。

 Gitee

GPT-SoVITS For AB

Windows 一键包。丢进一段录音，完成分离、切片、转写和训练，然后在网页里出声。

 Gitee

五条悟 RVC

自带模型和索引。可以离线配音，也可以用麦克风实时变声，再接到语音软件。

 Gitee

FastSD 中文版

补过本地依赖，界面做成中文，给没有独显的机器用来画图。

 Gitee

Forge WebUI

面向 NVIDIA 显卡的 Stable Diffusion Forge 本地绘图整合。

 GitHub

PixelMask

在浏览器里给视频打马赛克。自己画区域、设时间段，文件不上传。

 GitHub

Yahoo Finance Python

用 yfinance 抓雅虎财经，旁边配了 FastAPI，方便直接调试接口。
